# MerchIntell — Known Limitations

## Scope & Implementation Boundaries

This document conservatively outlines current system boundaries based on the codebase implementation.

---

## 1. Inventory & Dataset Scope
- **Dataset Horizon**: Historical baseline dataset covers transactions from June 2025 to April 2026 across 40 stores.
- **Single-Location Mutations**: Live POS transactions decrement stock for the selected store outpost (`STR-1001` .. `STR-1040`). Inter-store automated transfer shipments simulate stock reallocation without physically integrating external logistics APIs.

## 2. Supplier & Procurement Integration
- **Reorder Execution**: Reorders generated by the decision engine update internal action logs (`merchant_autopilot.db`) and transaction states. Direct EDI or automated supplier API integration (e.g., SAP / Oracle SCM) is not currently connected.

## 3. Real-Time Hardware Connections
- **POS Hardware**: POS terminal inputs use web-based forms and software barcode simulation. Direct USB/RS232 physical barcode scanner drivers or physical thermal receipt printer spools use standard browser print dialogs (`window.print()`).

## 4. Multi-Tenant Authentication
- **User Sessions**: Designed as a single-merchant operational copilot role. Role-based access control (RBAC) and OAuth2 multi-tenant authentication are prepared for future enterprise expansion.
