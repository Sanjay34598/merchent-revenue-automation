# MerchIntell — Future Product Roadmap

## Vision

Transform MerchIntell into an enterprise-grade autonomous retail intelligence operating system for multi-national retail chains.

---

## Planned Phases

### Phase 1: Automated Supplier Integration (Q3 2026)
- **EDI / API Procurement Adapters**: Direct integration with supplier ERPs for automated purchase order submission upon merchant action approval.
- **Lead-Time Tracking**: Dynamic tracking of supplier shipment lead-times to refine stockout risk exposure models.

### Phase 2: Advanced Demand Forecasting Models (Q4 2026)
- **Deep Learning Demand Predictors**: Incorporating Temporal Fusion Transformers (TFT) and weather/event API feeds to enhance 30-day velocity predictions.
- **Dynamic Price Elasticity Engine**: Automated elasticity estimation to optimize clearance markdown percentages.

### Phase 3: Enterprise Multi-Tenancy & Role-Based Access (Q1 2027)
- **RBAC Roles**: Separation between Store Managers, Category Buyers, Regional Operations Directors, and CFOs.
- **Single Sign-On (SSO)**: SAML 2.0 / OpenID Connect integration for enterprise identity providers.

### Phase 4: Hardware POS & Scanner SDKs (Q2 2027)
- **Native Mobile POS App**: iOS & Android tablet POS application with barcode camera scanning and Bluetooth thermal printer integration.
